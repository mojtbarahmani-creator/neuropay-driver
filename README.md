# نورو پی — نمونه راننده

نمونه اولیه اندرویدی فارسی برای نمایش رابط راننده. دکمهٔ «شبیه‌سازی دریافت پرداخت» فقط وضعیت نمایشی را عوض می‌کند: رسید سبز با مبلغ ۳۵,۰۰۰ تومان نشان داده می‌شود و موجودی نمونه به ۴۲۰,۰۰۰ تومان می‌رسد. دکمهٔ بازنشانی، نمایش اولیه را برمی‌گرداند.

**این برنامه پرداخت واقعی انجام نمی‌دهد و قابلیت یا تضمین پرداخت آفلاین امن ندارد.** وضعیت آفلاین/آماده‌به‌کار صرفاً متن رابط نمایشی است. هیچ شبکه، کیف پول یا سرویس پرداختی در برنامه پیاده‌سازی نشده است.

## ساخت در Android Studio

1. Android Studio به‌روز را نصب کنید و اجزای Android SDK (حداقل API 23؛ برای ساخت API 35) را از SDK Manager دریافت کنید.
2. فایل ZIP را استخراج کرده و پوشهٔ `NeuroPayDriver` را با گزینهٔ **Open** در Android Studio باز کنید.
3. منتظر Gradle Sync بمانید؛ در صورت درخواست، JDK/Gradle و SDK پیشنهادی Android Studio را نصب کنید. اتصال اینترنت برای دریافت Android Gradle Plugin و کتابخانه‌های Compose لازم است.
4. گوشی را با USB وصل کنید، Developer options و USB debugging را فعال و مجوز رایانه را تأیید کنید؛ سپس دکمهٔ Run را بزنید.
5. برای APK: از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید. خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساخت و نصب با ADB

از داخل پوشهٔ پروژه:

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

در ویندوز از `gradlew.bat assembleDebug` استفاده کنید. اگر Gradle wrapper در محیط شما موجود نیست، ابتدا پروژه را در Android Studio باز کنید تا آن را آماده کند، یا Gradle نصب‌شدهٔ سازگار را اجرا کنید. برای نصب دستی می‌توان APK را به گوشی منتقل و اجازهٔ نصب از منبع ناشناس را برای همان برنامهٔ فایل‌گردان فعال کرد.

## مشخصات

- Kotlin و Jetpack Compose، حداقل Android 6.0 (API 23)
- رابط تیره با متن فارسی و چیدمان راست‌به‌چپ
- بدون دسترسی‌های حساس یا ارتباط شبکه
- شناسهٔ برنامه: `ir.neuropay.driver`
